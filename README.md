# java-lotto-precourse

---

## 1. 기본 조건

### 입력 조건

- [ ] 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.

### 로또 구입 금액

- [x] 구입 금액을 입력받는다.
- [x] 구입 금액에 해당하는 만큼 로또를 발행한다. (1,000원당 한 장)

### 로또 번호

- [x] 6개의 숫자를 뽑는다.

### 당첨 번호

- [x] 번호는 쉼표(,)를 기준으로 구분한다.
- [x] 당첨 번호는 6개의 숫자를 입력받는다.
- [ ] 보너스 번호는 1개의 숫자를 입력받는다.

### 당첨 내역

- [ ] 일치 번호 수와 개수를 출력한다.
    - [ ] 3개 일치 시 5,000원을 수령한다.
    - [ ] 4개 일치 시 50,000원을 수령한다.
    - [ ] 5개 일치 시 1,500,000원을 수령한다.
    - [ ] 5개와 보너스 볼 일치 시 30,000,000원을 수령한다.
    - [ ] 6개 일치 시 2,000,000,000원을 수령한다.

### 수익률

- [ ] 소수점 둘째 자리에서 반올림한다.

## 2. 프로그램 동작 조건

- [x] 구입 금액은 양의 정수여야 하며 1,000원으로 나누어 떨어지지 않는 경우 예외 처리한다.
- [x] 로또 번호는 중복될 수 없으며 1부터 45 사이의 숫자를 랜덤하게 뽑는다.
- [x] 당첨 번호는 중복될 수 없으며 1부터 45 사이의 숫자를 6개 입력받아야 한다.

## 3. 출력 조건

- [x] 발행한 로또 수량 및 번호를 오름차순으로 정렬하여 출력한다.
- [ ] 당첨 통계는 당첨 내역과 수익률을 함께 출력한다.

## 4. 테스트 코드 작성

### 입력 테스트
- [x] 구입 금액 입력 테스트  
    - [x] 공백 예외 처리  
    - [x] null 예외 처리  
    - [x] 정수가 아닐 시 예외 처리  
    - [x] 1,000원 단위가 아닐 시 예외 처리
- [x] 로또 번호 랜덤 추출 테스트  
    - [x] 6개가 아닐 시 예외 처리  
    - [x] 1에서 45 사이의 범위가 아닐 시 예외 처리  
    - [x] 중복 예외 처리  
    - [x] 오름차순 정렬이 아닐 시 예외 처리
- [ ] 당첨 번호 입력 테스트  
    - [ ] 6개가 아닐 시 예외 처리  
    - [ ] 중복 예외 처리  
    - [ ] 1에서 45 사이의 범위가 아닐 시 예외 처리  
    - [ ] 정수가 아닐 시 예외 처리  
    - [ ] 공백 예외 처리  
    - [ ] null 예외 처리
